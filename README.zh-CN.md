# Smart Sync 客户端

无界同步（国内）和 Smart Sync（海外）共用的客户端源码主线。[English](README.md)。

## 范围

同步核心共用，插件身份和服务地区独立。国内支持登录、免费套餐开通及购买续费入口，付款结果由服务端验证；海外包含英文界面、Google／GitHub／邮箱登录及独立支付入口，服务、存储和账号数据独立。公开源码不等于发布海外安装包或社区审核通过。语言不改变服务地区或账号，加密口令仍由用户保管。

这里保留26个运行模块、样式、资源、中外配置及合成测试。内部历史、运维发布工具和跨端验收资料保留在私有 obsidian-smart-sync-internal；Server 保留在私有 obsidian-smart-sync-server。公开测试不代表社区审核、预发、生产或真实设备验收通过。

桌面测试版在“高级配置”中提供“开机启动到托盘”，仅支持视窗系统，默认关闭。开启后为当前库建立独立启动项，同时启用后台托盘；登录系统后打开当前库并隐藏到托盘。手动打开仍显示窗口，账号、密钥、同步配置和手动停止状态保持。关闭托盘、卸载或回退到不支持此功能的版本前，应先关闭开机启动。插件重载不会删除启动项。实际注销或重启启动仍需用户联调验收。

## 构建

使用 Node 26.12.1，具体命令见英文 README。国内产物为 artifacts/cn，海外产物为 artifacts/global；构建不代表海外可发行。公开 CI 覆盖 Windows 和 Linux，不负责部署或发布。国内发行入口为 [obsidian-smart-sync-release-cn](https://github.com/adventurer2008/obsidian-smart-sync-release-cn)。

## 划词翻译

在 Markdown 编辑器中选中文字后点「翻译」。电脑在选区附近显示译文，手机和平板从编辑器选区工具栏触发，在底部面板查看。也可使用编辑器菜单或命令「翻译所选文字」。默认将中文译为英文，其他语言译为简体中文，面板内可更换目标语言并复制译文。

翻译使用当前无界同步登录或配对身份。点击后，只有选中文字和目标语言随翻译请求发往无界同步服务端，服务端转交给百度或火山引擎。每次最多 1000 字符。
